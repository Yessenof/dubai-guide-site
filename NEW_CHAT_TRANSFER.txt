RULES THAT MUST NOT BE BROKEN
------------------------------
1. Single form + intent pattern. One <form> with name="intent" buttons for
   Save draft / Save and publish. Unpublish only is allowed as standalone form.

2. Public/admin separation. Public pages: lib/db/reader.ts only.
   Admin reads: lib/db/writer.ts. Never cross-import.

3. proxy.ts not middleware.ts. Next.js 16 convention.

4. serverExternalPackages: ["better-sqlite3"] in next.config.ts. Must stay.

5. bcrypt hash in .env.local: escape $ as \$ to prevent dotenv-expand corruption.
   CONFIRMED BUG HISTORY: reset script wrote bare $ → dotenv-expand corrupted hash
   → authorize() returned null → 401. Fixed by re-escaping in runtime-env-diag.sh.

6. React key rule: outer <GuideEditForm key={saved ?? "init"}> handles remount.
   Inner siblings must not carry the same key value.

7. Timeline required. Guide timeline and step timeEst are required fields.
   Server actions throw if empty. Do not remove validation.

8. Content writing standard (CLAUDE.md). All new guides follow the field-level
   and style rules. Summary 1-2 sentences. Overview 2 paragraphs max.
   Step what = 1-2 sentences. No em-dashes. No AI verbosity.

9. Fee discipline: No AED ranges without official tariff backing. Name variation
   drivers when exact fee is unknown. Only retain ranges that are well-supported
   (e.g. medical fitness test AED 250-450).

10. After every meaningful step, update PROJECT_STATE.md, SESSION_LOG.md,
    and CHECKPOINTS.md before declaring done.

11. NEXT_PUBLIC_SITE_URL is baked at build time. Any domain change requires
    updating .env.local on server AND running npm run build before PM2 restart.
