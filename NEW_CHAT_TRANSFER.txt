WHAT THIS PROJECT IS
---------------------
A premium mobile-first Dubai knowledge hub. Owner-only admin panel. Content in
SQLite. No external services. Stack: Next.js 16 (App Router) + TypeScript +
Tailwind CSS v4 + better-sqlite3 + Drizzle ORM + NextAuth.js v4 + bcryptjs.

RULES THAT MUST NOT BE BROKEN
------------------------------
1. Single form + intent pattern. Never split guide field-editing and publish
   into separate <form> elements. Save draft / Save and publish = one form,
   name="intent" buttons. Unpublish only is allowed as standalone form.

2. Public/admin separation. Public pages: import only lib/db/reader.ts.
   Admin pages: lib/db/writer.ts for reads. Never cross-import.

3. proxy.ts not middleware.ts. Next.js 16 convention.

4. serverExternalPackages: ["better-sqlite3"] in next.config.ts. Must stay.

5. bcrypt hash in .env.local: escape $ as \$ to prevent dotenv-expand corruption.

6. React key rule: outer <GuideEditForm key={saved ?? "init"}> handles remount.
   Inner siblings must not carry the same key value.

7. After every meaningful implementation step, update PROJECT_STATE.md,
   SESSION_LOG.md, and CHECKPOINTS.md (if a milestone was reached) before
   declaring the step complete.
