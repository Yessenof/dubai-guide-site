# High-Value Event Detail Page Plan
## Phase 6C-97A | Research date: 2026-06-05

---

## Purpose

Internal Guidex event pages (/events/[slug]) serve three functions:
1. **SEO anchor** — stand-alone rankable article for high-volume queries
2. **RAG/AI value** — structured factual page that AI tools can cite with source attribution
3. **Calendar backlink** — calendar items link to the detail page for fuller context

Criteria for a detail page (any one):
- Major annual event with established search demand
- UAE resident relevance (not just tourist interest)
- Enough confirmed factual content to fill a quality article
- Existing calendar item already imported or planned
