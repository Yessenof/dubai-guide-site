Last updated: 2026-04-28

Priority labels: **High** / **Medium** / **Low** / **Long-tail**
No invented search volumes. Labels based on business relevance and query specificity.

Page types:
- **Guide** — step-by-step evergreen process article
- **Service** — commercial landing page (what we do, CTA)
- **Hub** — index page linking to related guides
- **Article** — explanation or comparison piece
- **Tool** — calculator or checker
- **Checklist** — user action list

## Page type decision guide

| Need | Use |
|---|---|
| User is doing a specific government process | **Guide** — step-by-step, evergreen |
| User is evaluating options (mainland vs free zone) | **Article** — comparison |
| User needs to find the right guide | **Hub** — links to relevant guides |
| User needs a specific number or estimate | **Tool** — calculator |
| User is executing a process themselves | **Checklist** — printable or interactive |
| Something has changed (fee, law, processing time) | **News** — short, dated, linked from guide |
| User wants to hire someone to do this | **Service page** — commercial, CTA-focused |

## Internal linking priorities

- Every guide links to its hub page (e.g., employment visa → /visas)
- Hub pages link to all relevant guides
- Document attestation is linked from all family visa guides (required step)
- Amer center is linked from all family visa and employment visa guides
- PRO services linked from all company setup guides
- Bank account guide linked from all company setup guides
- Calculator (`/find-my-visa`) linked from visas hub and employment visa guide

## Sitemap strategy

- EN sitemap: all published guides + hub pages + static pages
- RU sitemap: only pages where `ru_title` is non-empty
- Single `sitemap.xml` with `<xhtml:link rel="alternate">` entries for both languages
- Submit both language variants to Google Search Console under the same property
